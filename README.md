# ⏳ SONSUZ BEKLEYİŞ SİMÜLATÖRÜ ⏳

## Resmi Bilimsel Açıklama

Bu proje, insanlığın en kadim ve en kutsal deneyimini dijital ortama taşımak amacıyla geliştirilmiştir: **Sonsuz Bekleyiş**.

Dünya çapında yapılan 47 bağımsız araştırma (hiçbiri yayınlanmamış, çünkü araştırmacılar hâlâ sonuçları bekliyor) sonucunda kanıtlanmıştır ki:

- Otobüs her zaman 2 dakika sonra gelecek der
- Kuyrukta öndeki kişi "bir saniye" der ve 47 dakika konuşur
- Müşteri hizmetleri "sıradasınız" der ve sonsuza kadar orada kalırsınız
- WiFi şifresi "hemen geliyor" olur ama hiç gelmez

Bu yazılım, tüm bu deneyimleri **tek bir tuşla** yaşamanızı sağlar. Artık gerçek hayatta beklemenize gerek yok. Bilgisayarınız sizin yerinize beklesin.

## Kurulum

```bash
pip install sonsuzluk  # (paket yok, hayal gücü yeter)
python bekleyis.py
```
